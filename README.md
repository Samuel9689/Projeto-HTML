# 📚 Projeto HTML

Projeto acadêmico desenvolvido com o objetivo de praticar e demonstrar os conhecimentos básicos de **HTML**, criando páginas web organizadas e conectadas entre si.

## 🎯 Objetivo

O objetivo deste projeto é colocar em prática os principais conceitos aprendidos durante os estudos de HTML, como criação de páginas, utilização de textos, imagens, vídeos, links e organização do conteúdo.

## 🛠️ Tecnologias utilizadas

* HTML5

## 📂 Estrutura do projeto

```text
Projeto-HTML/
│
├── img/
│   └── Imagens utilizadas no projeto
│
├── inicio/
│   └── Páginas relacionadas ao conteúdo principal
│
└── video/
    └── Vídeos utilizados no projeto
```

## 📖 Conteúdos abordados

Durante o desenvolvimento do projeto foram utilizados diferentes elementos e recursos do HTML, incluindo:

* Estrutura básica de documentos HTML;
* Títulos e parágrafos;
* Links entre páginas;
* Imagens;
* Vídeos;
* Listas;
* Tabelas;
* Formulários;
* Organização de conteúdo em diferentes páginas.

## 🎓 Projeto acadêmico

Este projeto foi desenvolvido como atividade acadêmica para praticar os fundamentos de desenvolvimento web e a utilização da linguagem HTML.

O projeto busca demonstrar a aplicação dos conhecimentos adquiridos durante as aulas de forma prática e organizada.
